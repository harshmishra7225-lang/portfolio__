# Premium Portfolio Website

A complete, responsive personal portfolio built from scratch with Next.js App Router, TypeScript, Tailwind CSS, and Framer Motion.

## Pages

- Landing page with hero, avatar placeholder, CTAs, and featured summary
- About Me page with personal story, background, education, goals, and milestones
- Skills page with grouped skill cards, badges, and animated proficiency bars
- Hobbies page with a continuously animated, pause-on-hover gallery
- Contact Me page with accessible validation-ready form fields and contact placeholders

## Tech Stack

- Next.js App Router
- TypeScript
- Tailwind CSS
- Framer Motion
- Vercel-ready project structure

## Getting Started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

Create a production build:

```bash
npm run build
```

Start the production server:

```bash
npm run start
```

## Customization

Update the placeholder content in:

- `data/portfolio.ts` for name, bio, skills, hobbies, links, milestones, and contact details
- `public/images` for profile, hero, and hobby images
- `app/layout.tsx` for metadata and the production domain

## Deploying to Vercel

1. Push this project to GitHub.
2. Import the repository in Vercel.
3. Keep the default framework preset as Next.js.
4. Deploy.

No extra configuration is required for the current setup.
